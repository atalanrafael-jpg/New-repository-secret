# Security Notice

This repository must never contain live credentials.

A credential was previously published here and the exposed file was removed from `main`. The previously exposed credential must be treated as compromised and must be revoked/rotated at its provider.

Do not add API keys, tokens, passwords, private keys, cookies, or other secrets to this repository. Use protected secret storage instead.

This repository is not a source of truth for MARSEL ROAPP credentials.
